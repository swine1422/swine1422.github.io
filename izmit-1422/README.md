# 伊兹密特 · 1422

可交互的 Three.js 山城场景：真实地形、城墙、海湾、清真寺、大浴场与接墙驻军堡垒。拖动旋转，滚轮缩放，右键平移；点建筑名称查看近景。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库，例如 `izmit-1422`。
2. 将本文件所在目录的**全部内容**上传到仓库根目录。根目录应直接包含 `index.html`、`data/` 和 `vendor/`，不要再套一层文件夹。
3. 打开仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/ (root)**，点击 **Save**。如果实际分支名称不同，选择上传文件的那个分支。
4. 等待 Pages 部署完成，从该设置页打开网站地址。

`.nojekyll` 用于直接发布静态文件。网站使用相对路径，兼容 `https://用户名.github.io/仓库名/`，无需修改域名或仓库名。

**发布不需要 npm、构建命令、后端、API Key 或 CDN。** Three.js 0.170.0、地形和建筑数据已随包附带；只有点击资料中的外部链接才会访问其他网站。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8080/>。不要直接双击 `index.html`：浏览器会限制本地文件的模块和 JSON 加载。使用支持 WebGL 2 和 import maps 的现代浏览器。

## 文件与修改

- `index.html`：页面入口、控件和资料说明。
- `scene.js`：建筑、地形、灯光、相机、交互与指北针。
- `layout.js`：城墙、道路、城门和地标的共同坐标来源。
- `style.css`：页面样式与窄屏布局。
- `data/`：页面实际使用的地形、建筑轮廓和海岸 JSON。
- `vendor/three/`：Three.js、两个插件及 MIT 许可证。
- `sources/modern-map-reference.png`：城墙范围的地图参照。
- `THIRD_PARTY_NOTICES.md`：数据来源与第三方许可。

直接修改对应文件并提交即可更新网站。修改带有 `?v=` 的 JS/CSS 文件时，同时更新引用它的版本字符串，避免旧缓存；入口引用在 `index.html`，`layout.js` 的引用在 `scene.js`。

## 场景设定

所有水平尺寸和高程以米建模，比例为 1∶1。

- 城墙约 **1,630 × 1,630 m**；主城门位于橙色主路与南墙交点，距南边中点约 38 m。
- 清真寺中心 **40.768501° N，29.919695° E**，主体约 **18.44 × 29.10 m**。
- 大浴场中心 **40.766990° N，29.920699° E**，主体约 **18.60 × 21.09 m**。
- 驻军堡垒约 **100 × 86 m**，位于主门西侧城墙内，南侧接墙、北门接城内道路。

两座公共建筑按现代地图定位；建筑高度和历史外观、城墙范围、堡垒选址及聚落布局属于小说复原。地形和简化海岸参照现代资料。
